# DataSci — Kaggle Learning Journey

Self-paced path from zero to **internship-ready data science** in 6–8 weeks, built on
[Kaggle Learn](https://www.kaggle.com/learn) courses.
The full roadmap lives in
[`.agents/skills/datasci-kaggle-roadmap/SKILL.md`](.agents/skills/datasci-kaggle-roadmap/SKILL.md).

## How to work through a module

1. Watch the course videos (1.5x is fine) and **code along** — don't just watch.
2. Do every exercise in the module folder — they're not optional.
3. Claim the certificate, then log progress at the bottom of this README.
